# Haeckel/php-basic-bcmath-calculator

Implementation for Haeckel\BasicDecimalArithmetic\CalculatorInterface based on ext-bcmath

## Features

- a bcmath backed calculator implementation

## Installation

Install the package vai composer by running:

```sh
composer require haeckel/basic-bcmath-calculator
```
